Financial Options Tracker

A professional-grade Google Sheets system for tracking financial options, featuring automated Greeks, real-time underlying quotes, and historical/live FX rate management.

🚀 Key Features

  • Automated Greeks: Fetches Delta, Gamma, Theta, IV, Volume, and Open Interest using CBOE (American) and IBKR (European) APIs.
  • Real-time Quotes: Updates underlying stock prices using a high-performance Google Finance workaround.
  • Smart FX Management:
    • Live rates for open positions.
    • Historical rates for closed positions (based on the close date).
    • Permanent caching via PropertiesService.
  • Enhanced UI: Expiry date gradients, automatic row formatting, smart sorting, and a toggle to hide/show closed operations.

📂 Project Structure

  • core.gs The central engine. API logic and batch updaters.
  • ui.gs User interface, menus, and visual helpers.

🛠️ Configuration

All settings are at the top of core.gs.

1. API Keys

  • IBKR: Required for European options. Set IBKR_CONFIG.API_KEY.
  • CBOE: Public API for American options.

2. Sheet Setup

Expected sheet name: "Opciones".

  • Col AJ: OCC String (Input)
  • Col AL: Is Closed? (Boolean)
  • Col P-W: Greeks Output
  • Col M: FX Rate Output

⚙️ Automation

Install triggers via the ⚙️ Utilities menu:

  • Quotes: Every 5 minutes.
  • Greeks: Every 15 minutes.
  • FX: Every 15 minutes.

📋 FX Backfill Mode

To recalculate historical rates for old rows:

  1. Set FX_CONFIG.BACKFILL_CLOSED: true in core.gs.
  2. Run Update FX Now.
  3. Revert to false once finished.
